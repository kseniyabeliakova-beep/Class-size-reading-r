# Class Size and Reading Achievement in R

This repository contains my R code for an ARE 106 homework assignment at the University of California, Davis. The assignment examines the relationship between class size and reading achievement using course data described as fourth- and fifth-grade classrooms in Israeli elementary schools in 1991.

## Analysis

The script:

- Estimates an OLS regression of log reading scores on log class size.
- Adds a control for the percentage of students from disadvantaged backgrounds.
- Estimates a first-stage regression of log class size on log rule-predicted class size and the disadvantage control.
- Estimates a two-stage least squares model using Maimonides' rule as an instrument for class size.

The IV model uses the variation in predicted class size generated by an enrollment-based classroom rule. A causal interpretation depends on the instrument's relevance, exogeneity, and exclusion assumptions; using an instrument does not by itself establish causation.

## Data

The course file is named `ARE106_HW5_S2025.Rdata` and contains a dataset called `D`. The variables used in the script are:

- `avgread`: Average classroom reading score.
- `classize`: Number of students in the classroom.
- `pct_dis`: Percentage of students from disadvantaged backgrounds.
- `m_rule`: Predicted class size under Maimonides' rule.

The course dataset is not included in this repository.

## How to run

1. Install R and, optionally, RStudio.
2. Install the `AER` package once with `install.packages("AER")`.
3. Obtain an authorized copy of the course dataset.
4. The script retains the original Posit Cloud path, `/cloud/project/ARE106_HW5_S2025.Rdata`. To run it on your own computer, update the path in `load()` to the location of your data file.
5. Run the code in order. Regression summaries appear in the console.

The script uses the default standard errors reported by `lm()` and `ivreg()`. It does not create or automatically save graphs or result tables.
